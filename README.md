# Padrões de Projeto

Repositório desenvolvido durante os estudos da disciplina de **Padrões de Projeto**, reunindo atividades práticas e projetos desenvolvidos ao longo das aulas.

## 📂 Projetos

### 📝 PP

Conjunto de atividades desenvolvidas durante as aulas, utilizando principalmente **HTML** para colocar em prática os conteúdos estudados.

Inclui atividades realizadas em sala e atividades propostas para casa.

### 👾 Monstrinho-PJ

Projeto de um **monstrinho virtual**, desenvolvido com:

* HTML
* CSS
* JavaScript
* Imagens
* Áudio

O projeto trabalha a interação com o personagem e diferentes estados visuais do monstrinho, utilizando programação para controlar seu comportamento e sua interface.

## 🎯 Objetivo

Este repositório faz parte da minha trajetória acadêmica e reúne projetos desenvolvidos para praticar conceitos de **programação, organização de código e padrões de projeto**.

## 🛠️ Tecnologias

* HTML5
* CSS3
* JavaScript
